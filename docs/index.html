REMEDA Stage328

QSP Evidence Match Gate

Overview

Stage328 extends the Stage327 reproduction evidence schema into a verification decision engine.

Instead of merely structuring evidence, Stage328 determines whether the AI security claim and reproduction evidence are truly bound together.

This is not a vulnerability reproduction system. It is an evidence trust verification engine.

Decision Rules

accept: all checks are true

pending: target/evidence exist but SHA256 or signature missing

reject: target mismatch or evidence missing

Core Idea

Stage327 structured reproduction evidence.

Stage328 verifies whether that evidence truly matches the AI claim, then converts the result into: 

accept / pending / reject
